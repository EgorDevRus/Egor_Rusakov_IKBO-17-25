# Эмулятор оболочки (практика 1, этапы 1–3)

Консольный эмулятор UNIX-подобной оболочки. Реализованы REPL с
приглашением `user@host:path$`, разбор аргументов в кавычках, команды
`ls`, `cd`, `exit`, параметры командной строки, стартовые скрипты и
виртуальная файловая система (VFS) из CSV-файла.

## Запуск

```bash
cd practical_1/2_part
./run.sh --vfs data/vfs_full.csv --script data/startup.txt
```

Параметры:

- `--vfs` — путь к CSV-файлу с описанием VFS;
- `--script` — путь к стартовому скрипту с командами эмулятора.

При запуске выводятся значения обоих параметров, затем выполняются
команды скрипта и открывается интерактивный режим.

## Структура

- `src/` — код эмулятора: разбор ввода, оболочка, VFS, конфигурация;
- `data/` — варианты VFS и стартовые скрипты;
- `scripts/` — скрипты реальной ОС для проверки разных режимов запуска;
- `tests/` — модульные тесты.

## VFS

CSV-файл содержит столбцы `path,type,content`. Каталоги имеют тип
`dir`, файлы — `file`; содержимое файлов хранится в base64. VFS
загружается в память, исходный файл не изменяется.
